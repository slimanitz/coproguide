# User stories

Personas: **Claire**, copropriétaire and member of her conseil syndical; **Mehdi**, tenant of an
unfurnished flat; **Sophie**, landlord of a furnished studio; **Thomas**, the product's tech lead.

1. **Ask a copropriété question with sources** — As Claire, I want to ask in plain French which
   majority applies to a decision so that I can prepare the next general assembly.
   - Given the corpus is ingested, when I ask "Quelle majorité pour voter des travaux
     d'amélioration ?", then the answer streams in and cites article 25 of the loi du 10 juillet
     1965 with a clickable chip.

2. **Read the cited article** — As Claire, I want to open the article behind a citation so that I
   can check the wording myself.
   - Given an answer with citation chips, when I click "art. 25 (loi 65-557)", then a side panel
     shows the full article, its law, the reproduced version date and a link to Légifrance.

3. **Be told when the assistant does not know** — As Mehdi, I want the assistant to refuse rather
   than invent when my question is outside its texts.
   - Given a question about commercial leases or taxes, when retrieval confidence is below the
     threshold or the model answers `[HORS_CORPUS]`, then I see a highlighted refusal that points
     to Légifrance and the ADIL/ANIL, and no article is cited.

4. **Tenant notice period** — As Mehdi, I want to know my notice period so that I can plan my
   move.
   - Given I ask "Quel est le préavis du locataire pour quitter un logement vide ?", then the
     answer explains the 3-month rule and the 1-month cases, citing article 15 of the loi du 6
     juillet 1989.

5. **Follow-up questions** — As Sophie, I want to ask a follow-up in the same conversation so
   that I don't repeat the context.
   - Given a conversation about a furnished lease, when I ask a follow-up, then the previous
     non-refused turns are sent as history and the new answer stays in the same thread.

6. **Manage conversations** — As Claire, I want my past conversations listed and deletable.
   - Given previous questions, when I open the home page, then the sidebar lists them by last
     activity; when I delete one, it disappears with its messages and citations.

7. **Browse and search the sources** — As Sophie, I want to browse the articles the assistant
   relies on.
   - Given the Sources page, when I type "dépôt de garantie" or filter on the loi de 1989, then
     only matching articles are listed, each expandable, under a banner stating that the
     extracts are for demonstration and that Légifrance is authoritative.

8. **Disclaimer everywhere** — As the publisher, I want every page to state that this is legal
   information, not advice.
   - Given any page, then the footer shows the disclaimer with links to Légifrance and ANIL.

9. **Run the evaluation harness** — As Thomas, I want to run the 50-question golden set so that
   I can detect regressions in retrieval and answers.
   - Given the database is ingested, when I run `pnpm eval` (or click "Lancer une évaluation"),
     then a run is stored with recall@5/@8, citation precision, refusal accuracy, judge score,
     latency and cost, and a JSON + Markdown report is written to `evals/reports/`.

10. **Inspect an evaluation run** — As Thomas, I want per-question results so that I can
    understand failures.
    - Given a finished run, when I open it on /evals, then I see each question with expected vs
      cited articles, recall, judge score and rationale, and failures are flagged.

11. **Monitor cost and latency** — As Thomas, I want a dashboard of requests, cost, latency and
    cache efficiency.
    - Given chat and eval traffic, when I open /dashboard and choose 7/30/90 days, then I see the
      four KPI tiles, cost per day, p50/p95 latency per day and the token split, with a table
      view of the same data.

12. **Run offline without a key** — As a recruiter trying the project, I want the demo to work
    without any API key.
    - Given a fresh clone, when I run `docker compose up -d --build`, then the app on :3400
      answers with the mock provider, citing real articles, and the corpus is ingested
      automatically.

13. **Switch to Claude** — As Thomas, I want to switch to the real model with one variable.
    - Given `LLM_PROVIDER=anthropic` and `ANTHROPIC_API_KEY`, when a question is asked, then the
      answer is generated by Claude Sonnet 5.5 with a cached system prompt, and usage (including
      cache reads) is stored and priced.

14. **Refresh the corpus from Légifrance** — As Thomas, I want to update the articles from the
    official API.
    - Given PISTE credentials, when I run `pnpm fetch:legifrance` then `pnpm ingest`, then the
      corpus files are rewritten with the current consolidated text and only changed articles
      are re-embedded.
